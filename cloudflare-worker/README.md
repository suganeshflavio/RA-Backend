# B2 CDN Worker

Fronts Backblaze B2 with a Cloudflare-branded domain so video reads (1-2GB
files, scrubbed via Range requests) go through Cloudflare's edge and the
Backblaze+Cloudflare Bandwidth Alliance (free egress between the two)
instead of hitting `*.backblazeb2.com` directly.

The backend still does all signing — `getB2SignedUrl` in
`src/utils/b2.ts` builds a normal B2 download-authorization URL. This Worker
just proxies that same path/query to B2's real host, forwarding Range
headers so seeking works.

## First-time setup

1. `npm install -g wrangler` (or use `npx wrangler` everywhere below).
2. `wrangler login` — authorizes the CLI against your Cloudflare account.
3. Find your B2 account's download host: it's the `downloadUrl` field
   returned by B2's `b2_authorize_account` (e.g. `f005.backblazeb2.com`).
   You can log it once from the backend by temporarily printing
   `(await authorizeB2()).downloadUrl` from `src/config/b2.ts`.
4. Put that host in `wrangler.toml` under `[vars] B2_DOWNLOAD_HOST`.
5. From this folder: `npm install && npm run deploy`.
6. In the Cloudflare dashboard: Workers & Pages → `tksacademy-b2-cdn` →
   Settings → Domains & Routes → add a custom domain (e.g.
   `cdn.yourdomain.com`). This requires the domain's DNS to already be on
   Cloudflare (orange-clouded).
7. In the backend's `.env`, set `CDN_BASE_URL=https://cdn.yourdomain.com`.
   From then on, every signed video URL the API returns will be rewritten
   to that domain automatically — no other backend changes needed.

## Local testing

`npm run dev` runs the Worker locally with `wrangler dev`; it still talks to
real B2, so signed URLs generated by the backend (pointed at the `wrangler
dev` local URL via `CDN_BASE_URL`) will work end-to-end before you deploy.

## Notes

- No B2 credentials live in the Worker — it only forwards the
  already-signed `Authorization` query param the backend generated, so
  there's nothing secret to configure beyond the download host.
- PPT/PDF notes are **not** routed through this Worker — they stay on
  Cloudinary's own CDN. Only video (B2) reads go through here.
